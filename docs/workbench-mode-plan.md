## 0. 一句话

**工作台 = 一个把「创作模式」收进一条长条窗口的门面**：你和主 agent 的对话永远在中间那条，
需要哪个模式，就从右缘把它「拼」到旁边——拼出来的是一块独立窗口，可以再拖开、也能拖回来。

工作台**不实现任何创作能力**：写作还是写作模式、生图还是 GIR，它只负责**入口、当前是谁、上下文、拼接与交接**。

三条定位（决定了后面所有"为什么不那样做"）：

1. **纯插件、零内核改动**：跑在官方壳上也成立；壳能力缺席时降级（§3.3）。
2. **门面归插件，能力归壳**：窗口形态、开窗、置顶、关窗语义归外壳；插件只说"我要长条 / 我要拼一块"。
3. **不统一领域数据**：写作的作品库、GIR 的项目库各归各的；共享的是**句柄与现场**，不是存储。

## 1. 名词（先说清楚，否则后面对不上）

| 词 | 指什么 |
|---|---|
| **工作台** | 本次统一口径的总称。**代码与 UI 里目前仍叫「工具台」**（见 §11 改名清单） |
| **长条**（`strip`） | 进入工作台后主窗收到的形态：420 宽、贴工作区右上角、对话优先 |
| **小条**（`mini`） | 再收一档：300×168、右下角，只剩顶栏 + 一行"正在做什么" + 紧凑状态条 |
| **宽窗主屏** | 主窗是普通大小（`normal`）时的界面：左对话 + 右模式瓷砖格。**壳能力缺席时它就是正式形态**，自研壳上它是"工作区选择"这一层 |
| **接缝** | 长条右缘那条 26px 的热区；悬停弹出扇形模式图标。**长条下它是唯一的模式入口** |
| **拼接 / 分离** | 点接缝里的模式 = 给它开一块**独立窗口**贴在长条旁边；把它拖走 = 分离；拖回附近 = 吸附拼回 |
| **助手窗口** | 某些模式（写作模式）声明 `splice.assistant` 后，拼接时**额外**在长条左侧开的一块该模式的助手对话窗 |
| **模式** | 一个可被工作台接入的创作能力（写作 / GIR 生图 / 将来的导演），由各插件自己实现 |

### 1.1 形态一句话对照

| 形态 | 用户看到什么 | 什么时候出现 |
|---|---|---|
| `normal` 宽窗主屏 | 左：对话列；右：模式瓷砖格（内容窗口或大按钮卡） | 点侧栏「工具台」而壳没有长条能力；或点长条顶栏 `←` 回到这一层 |
| `strip` 长条 | 一条 420 宽的竖窗：顶栏 + 对话 + 输入 + 状态条；右缘接缝 | 自研壳上点入口的**默认**形态 |
| `mini` 小条 | 300×168：顶栏 + 一行正在做什么 + 紧凑状态条 | 点顶栏 `—` |
| 拼接（模块窗口） | 长条 + 右侧模式完整界面（+ 左侧助手窗） | 点接缝里的某个模式 |

- **最近打开**、**健康总览**（契约留了 `recent` / `health` 字段，未实现）。

## 3. 形态分工（最重要的一条规则）

### 3.1 谁来定形态

**壳是形态的唯一事实源，门面只跟随。** 页面可以申请档位（`normal` / `strip` / `mini`），
但最终显示以壳回报为准——G6 的教训就是门面自己记了一份、壳被外部改了之后对不上，接缝整块消失。

### 3.2 分工表

| 场景 | 形态 | 界面 | 模式入口 |
|---|---|---|---|
| 自研壳（有 `window.dshShell` 形态能力） | **长条** | 对话优先，**不摆瓷砖格** | **右缘接缝**（点一下 = 拼到旁边） |
| 官方壳 / 老安装包 / 探针假宿主 | 宽窗主屏 | 左对话 + 右瓷砖格 | 瓷砖「进入」（真正切模式） |
| 用户点了 `←` | 宽窗主屏 | 同上（= 原型里的"工作区选择"） | 瓷砖「进入」 |
| 用户点了 `—` | 小条 | 顶栏 + 一行 + 紧凑状态条 | 无（先回长条） |

**为什么不做"长条里也摆瓷砖格"**：420px 宽塞瓷砖必破版（用户实报过"长条内容不对"）。
瓷砖格属于宽窗，这是硬分工，不是审美偏好。

### 3.3 降级（硬约束）

- 壳能力缺席 → 需求自动退回宽窗主屏，**一个字都不发**（不发还原、不留死按钮）。
- 工作台缺席 → 各模式保留自己的入口与开关（官方壳兼容）。**这条不许破**：
  把模式绑死在自研壳上，等于在别人环境里直接不可用。

### 3.4 记住什么、不记住什么

- **记住**用户把长条拖到了哪里（按形态分别记）；重启后长条**回到 `normal`**（否则会一直停在条状）。
- **绝不**把条状尺寸写进普通窗口记忆（否则下次启动窗口是 420 宽）。
- 拼接宽度记忆在壳里，重开时按屏幕重新夹一次。

## 4. 主流程（用户视角，一条一条走）

> 每条都写"用户做什么 → 期望发生什么 → 失败时说什么"。**"失败时说什么"是硬要求**：
> 静默失败是最贵的 bug（G8/G9/G10 全是同一类）。

### 流程 1 · 进入工作台

1. 点侧栏底部「工具台」。
2. 自研壳：窗口**收成长条**（420 宽、贴右上角、置顶可关），对话列直接可用。
   官方壳：开宽窗主屏。
3. 只有**一个**模式都没注册时，入口**不渲染**（宁可没按钮，也不留死按钮）。

**失败时说**：形态申请失败 → 界面照常显示，不弹自造错误文案（形态是增强，不是前提）。

### 流程 2 · 在长条里跟 agent 说话

- 中间是转录（最近若干条，长文默认折三行 + 「展开全文（N 字）」），下面是输入框 + 发送，
  再下面一条状态条（`⚡ tok/s · 缓存 % · 上下文 已用/窗口`）。
- 三态必须分清：**正在读**（"正在读取这条会话的内容…"）/ **空**（"还没有消息…"）/ **读不到**（"暂时读不到…"）。
  把"正在读"错报成"空"，用户会以为会话丢了。
- 正在生成时摆**流式态**（呼吸点 + "正在生成…"），与空态**互斥**。
- 发送三态：接受 / 拒绝 / 结果不可核。**只有确认接受才清输入框**，另两种一个字都不丢，并给可执行出路。

### 流程 3 · 拼一个模式到旁边

1. 鼠标放到长条**右缘**（26px 热区，中间一道小指示条）。
2. 模式图标**以接缝为轴心按角度弹开**（中间 0°、两端 ±34°、半径 58px、逐颗错峰 45ms），
   图标与文字反向旋转保持正立；每颗下面一行「正在做什么」，右下角小圆点表示"当前/已拼接"。
3. 点一个：**给它开一块独立窗口**贴在长条右侧；模式若声明了助手窗口，长条**左侧**同时开一块助手对话。
4. 再点同一个模式 = 关掉它的窗口（含助手窗）。

**失败时说**：

- 壳不支持（老壳）→ 入口不出现，不摆一个点了没反应的图标。
- 开窗失败 → toast 说"没开成"并**保持界面原样**（不许画到窗口外）。
- 模式没有可嵌入视图 → 如实说"还没提供可嵌入视图"，不硬塞轻视图冒充完整界面。

### 流程 4 · 把拼接块拖开 / 拖回来

- 拖动**结束**才判定（拖动中判会把"手抖"当"分离"）：离目标位 ≤ **32px** 且纵向也接近 → **吸回去**；
  拖远了才算**分离**，接缝上标「已分离」，壳不再管它的位置。
- 已分离的拖回目标位附近 → **吸附拼回**（同一套阈值）。
- 分离的那块**不会**跟着工作台一起关——它的语义就是"拆下来独立活着"。

### 流程 5 · 长条移动 / 变小

- 拖长条（抓顶栏那条空白）→ 还贴着的模块窗口**跟着平移**，尺寸不变。
- 长条变宽/变高 → 模块重新贴边排布（放不下就缩，**下限 220**；助手窗下限 **160**，宁可窄也不压长条）。

### 流程 6 · 回宽窗 / 退出 / 关窗（三件事别混）

| 钮 | 语义 | 会发生什么 |
|---|---|---|
| `←` | 回**宽窗主屏**（工作区选择） | 先收起拼接；窗口变宽；主屏还在，瓷砖格出现；**不退出**工作台 |
| `退出` | 退出工作台，回内核主界面 | 先收起拼接 → 有模式在场先过它的**关闭守卫**（被拦就留在原地，不自造文案）→ 还原窗口 |
| `✕` | 关这个窗口 | 走**既有**关窗语义（默认收进托盘，不退出应用）；**不改形态、不改置顶** |

> 原先 `⎋` 这个字形没人认得出（用户直接问"怎么回到主界面"），2026-10-13 已换成**文字「退出」**。
> 这是一个可复用的教训：**出口用字，不用符号**。

### 流程 7 · 小条

`—` 在 长条 ⇄ 小条 之间切。小条只有：顶栏 + 一行「当前模式 · 正在做什么」+ 紧凑状态条。
`Esc` 在小条下等价于「退出」。**小条里收掉的对话不吞字**：没发出去的正文记在内存里（刻意不落盘），展开回来还在。

### 流程 8 · 交接（模式之间递东西）

写作台的「去生图」→ 先切到 GIR（走同一套守卫）→ 把一段**不透明载荷**交给它。
如实语义：目标没有接收端 → toast 说"还没有接收端，引用没有送出去"；被守卫拦下 → 不切也不交付。

## 5. 交互细则（可调参数的单一清单）

### 5.1 窗口档位

| 档位 | 尺寸 | 位置 | 最小尺寸 |
|---|---|---|---|
| `normal` | 用户自己的窗口记忆 | 用户位置 | 980×640 |
| `strip` | 宽 **420**，高 = 工作区 × **0.86** | 工作区右上角 | 320×320 |
| `mini` | **300×168** | 工作区右下角 | 240×120 |

几何**一律主进程算**，页面只能发档位字符串——这条是安全边界，不是实现细节。

### 5.2 接缝扇形

| 参数 | 值 | 为什么是这个值 |
|---|---|---|
| 热区宽 | 26px（展开时 132px） | 展开时必须盖住扇形，否则鼠标挪过去的中途就出了热区（实报过"还没挪过去就消失"） |
| 收起宽限 | 240ms | 同上；进到图标上就取消收起 |
| 角度 | 中间 0°，两端 ±34° | 照原型；**第一颗在上、最后一颗在下**（反了会像"朝内翻"） |
| 半径 | 58px | 原型动效终点 |
| 错峰 | 45ms/颗 | 逐颗弹出手感 |
| 位置 | 没拼接贴右缘；拼接后站在**拼合处** | 原型规则："已有模式拼着时，鼠标放在拼合处" |

### 5.3 拼接与模块窗口

| 参数 | 值 | 备注 |
|---|---|---|
| 模块窗口最小/最大宽 | 280 / 900 | 壳夹住 |
| 贴边排布下限 | 220 | 放不下就缩 |
| 助手窗下限 | **160** | 长条左边常常只剩一百多像素；压着 220 会重叠在长条上 |
| 缝宽 | **-8px**（负重叠） | 视觉上拼成一体，不露缝 |
| 吸附阈值 | **32px**（横纵都判） | 手感旋钮：嫌松降到 24/16，嫌黏升到 40/48 |
| 拖动判定防抖 | 240ms | `moved` 与 `move` 双路都走同一个幂等判定 |
| 默认拼接宽 | 420 | 模式可用 `splice.width` 覆盖（写作台声明 **720**，三栏塞不进 420） |
| 降级路径宽度 | 280 – 1200（按工作区算） | 老壳走"窗内撑宽一列" |

**模块窗口的形态**：无边框、无阴影、**不可拉伸**（尺寸归壳管）、整窗跟着长条走。
拖动靠页面里的拖拽区（`-webkit-app-region: drag`），拖远即分离。

### 5.4 层级与让位

- 层级（从高到低）：接缝 **2210** > 主屏 **2200** > 坞 **2100** > 通知 toast **1410**。
- **长条与小条下面不显示辅助坞**：坞的轨也在右缘，会和接缝抢同一块地方（实报过"点了 rail 以为点的是扇形"）。
- **模块窗口里不显示坞**：那块窗口本身就是"这个模式的界面"，再给一个"切到某模式"的入口是重复。
- 模式可以让位：`--dsh-wb-dock-width` / `--dsh-wb-strip-w` 由工作台写进 CSS 变量。

## 6. 状态矩阵（界面该显示什么）

### 6.1 模式 × 界面

| 模式的状态 | 接缝上的表现 | 宽窗瓷砖格里的表现 |
|---|---|---|
| 未接入 / 未加载 | 不出现 | 不出现 |
| 就绪 | 图标 + 名字 + 上下文 | 内容窗口（有 `tile`）或大按钮卡 |
| 当前（`activeModeId`） | 小圆点 + 「当前」 | 卡片标「当前」 |
| 已拼接（`anchored:true`） | 小圆点 + 「已拼接」 | —（宽窗里没有拼接） |
| 已分离（`anchored:false`） | 「已分离」（与拼接区分开） | — |
| 有未保存 / 保存中 / 体检 N | 小标记（不只靠颜色，带文字） | 同左 |
| 上下文报不出来 | **空着**，不编造 | 空着 |

### 6.2 对话列三态

| 状态 | 文案 | 触发条件 |
|---|---|---|
| `pending` | 正在读取这条会话的内容… | 通道在，图还没送到 |
| `no-messages` | 还没有消息… | 空会话（**不是**"读不到"） |
| `none` / `no-service` | 暂时读不到… | 没有会话服务 / 没有会话 |
| 流式 | 正在生成… + 当前 tok/s | `running:true`，与空态互斥 |

### 6.3 数值缺失

三指标全都可能没有：`sessionStats` / `tokenUsage` / `contextPressure` 都是可选投影。
**算不出就写"还没数据"并说明原因，绝不拿 0 冒充"没有"**。没有会话时整条状态条不摆。

## 7. 文案与反馈纪律

1. **单一出口**：所有文案在 `plugin/workbench/src/client/copy.js`，将来本地化只改这一处。
   组件里不写散装中文。
2. **先结论再原因，必须带出路**：不出现"失败了"这种没有下一步的句子。
   例：「拼接没成功（no-splice-bridge）——窗口没变宽，界面保持原样。」
3. **禁用按钮 = 点了没反应**（G9/G10 的根因）。宁可让按钮可点、点下去如实提示原因，
   也不要把按钮置灰只把原因写在 `title` 里——没人会去悬停。
4. **状态不只靠颜色**：失败要带"失败"两个字（如工具活动行）。
5. **不编造**：上下文、健康、时间戳、模型名，拿不到就空着。
   （例：内核 chat 节点只有 `seq`，**没有墙钟时间**，所以对话里只有"今天"这种日期分隔，不编造历史时间。）
6. **窗外的桌面不是画布**：窗口边界是硬的，扇形与拼接只能收在窗内贴边。
   想要"朝窗外张开"必须新增壳能力（透明置顶辅助窗），而它的最小切片已被否掉（"这个浮标没有用就去掉"）。

## 8. 体验验收清单（改完自问，能写进探针的就写进断言）

**形态**

1. 自研壳点入口 → 申请 `strip` 且真的变成 420 宽；关闭 → 申请 `normal`；"从没收成过条就绝不发还原"。
2. 壳外部改形态（小条往返 / 程序化 set）→ 接缝与顶栏**跟着壳变**，不出现"按钮没反应"。
3. 桥缺席 → 宽窗主屏，瓷砖格在，零横向溢出。

**接缝**

4. 长条下**只有一个**模式入口（接缝），没有坞的轨。
5. 扇形：第一颗在上、正中 0°、半径恒定、逐颗错峰单调；展开时命中区覆盖扇形；离开后 240ms 内回来不收。
6. 每颗都能看到：名字、上下文、忙标记、"当前/已拼接/已分离"。

**拼接**

7. 点一下开窗（右侧），声明了助手的同时开左侧；再点关掉两块。
8. 拖 30px 松手 → 吸回；拖 200px 松手 → 标「已分离」；再拖回 → 吸附拼回。
9. 长条移动时贴着的跟着走、尺寸不变；关工作台时**分离的不关**。
10. 老壳 → 窗内撑宽降级，且**绝不**把界面画到窗口外。

**退出三钮**

11. `←` 只回宽窗、**不退出**、瓷砖格回来；`退出` 走守卫且还原窗口；`✕` 只关窗、不改形态不改置顶。

**对话与状态**

12. 三态文案准确（正在读 ≠ 空 ≠ 读不到）；流式与空态互斥。
13. 发送：只有确认接受才清输入框；拒绝/不可核时正文不丢。
14. 指标缺失写"还没数据"，不出现占位的 0。

**通用**

15. 1280×800 不出现横向滚动；长标题/长模式名截断而不挤坏布局。
16. 键盘可达：入口/顶栏/接缝/瓷砖都能 Tab 到、焦点可见；`Esc` 在主屏与小条下都有明确语义。
17. 控制台零 error。

## 9. 已知边界（当前实现的真实限制）

- **主窗与模块窗的无缝**：主窗已改无边框（`frame:false` + 系统三钮叠层 + 顶部拖拽带），
  模块窗无边框无阴影；但**负缝 -8px 靠几何对齐**，跨屏缩放不同时仍可能差几个像素。
- **宽度是"抢来的"**：长条固定 420，助手与模式界面按剩余空间缩；屏幕太窄时先缩模式界面，
  再到助手下限 160，**再不够就重叠**——这一档当前不处理。
- **吸附阈值与宽限是拍的值**，等着上手摸过再定稿（§5.3）。
- **多屏**：两块屏缩放不同时，窗口必须**在目标屏上直接创建**，否则会被系统按目标屏再缩放一次
  （实测请求 420×601 得 481×688）。
- **助手窗口的现场同步到了"只读"**：能看、能说，但编辑权只在写作台那块窗口。
- **置顶是 OS 位、不是自报值**：只有 `screen-saver` / `pop-up-menu` 会真正置位，且 `isAlwaysOnTop()`
  会撒谎 ⇒ 门禁读 Win32 `GWL_EXSTYLE`，不信应用自报。
