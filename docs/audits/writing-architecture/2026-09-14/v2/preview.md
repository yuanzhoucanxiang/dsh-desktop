## 建议的验收步骤

1. **当轮上下文**：打开 `第1章-v1.md` → 输入区上方出现「参考项目备忘 · 2 条」→ 点开：每条都有
   "勾选=参考 / 取消勾选=不带 / 优先=排到最前"，右侧显示**本轮实际状态与来源**（固定带入 / 自动带入 /
   你已排除 / 超出预算省略）；顶部一行写明"本轮实际带入 N 条、另有 M 条超出 6000 字预算省略"。
2. **引用身份**：选中一段 → 「＋ 引用稿件 / 选区」→ 引用条写明来源（路径 / 版本 / 选区偏移 / 是否未保存）；
   改动该文件后引用会标出「引用来自旧快照 · 重新引用」。
3. **备忘完整操作**：点「项目备忘」→ 那条**候选**可确认/编辑/撤回/看历史；确认后才进入"可参考"；
   编辑已确认条目后历史里有 before→after 并可"恢复这一版"（产生新 revision）。
4. **恢复候选**（复核 B06 修的就是这条）：另起一个隔离实例（同一库根）写点草稿，当前窗口会出现
   「其他窗口还有未合并的草稿」→ 点"采用这一份"：**当前草稿会先被存成一份可恢复副本**（随后出现在候选里，
   可随时切回），引用按候选一起替换（候选没有引用就清空）。
5. **备忘读取失败**（复核 B04）：如果备忘接口出问题，点发送**不会发出**，正文与引用原样保留，
   并给"重试读取 / 不参考发送"两个按钮——不会再出现"提示一句然后照发并清稿"。
6. **会话协调**：点「会话设置 ↗」首次建立关联；重进复用同一会话；删除会话后重进会看到
   "原本关联的会话已不存在" + 恢复入口（继续关联会先找原会话，不会另建）。

## 真实模型体验（§6）——待有获授权的测试配置时执行

不索取密钥明文、不复制正式凭据到日志。三个场景（都在临时作品里做，不碰真实稿件）：

| 场景 | 操作 | 观察点 |
| --- | --- | --- |
| 1 随意谈人物动机、中途改口或暂不解决 | 聊"她为什么不拆信"，中途说"算了先不想这个" | 顺畅交流，不强行生成任务表/落盘，不假装记住了没确认的设定 |
| 2 候选设定 → 确认 → 修改/撤回 | 助手建议 → 消息上「记为候选」→ 确认 → 再编辑/撤回 | 只用当前有效设定；能说明不确定性；撤回后下一轮不再带入 |
| 3 先讨论，再明确要求改稿 | 讨论后说"按这个把第 1 章改成 v2" | 走 Harness 工具与权限流程；引用正确、旧版本保留、冲突不被覆盖 |
