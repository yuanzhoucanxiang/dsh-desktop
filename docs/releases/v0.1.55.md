# DeepSeek Harness Desktop 0.1.55

本版让**写作助手在官方 0.2.0 上真正可用**，并把写作台的信息架构又收了一轮。

## 写作助手：从「看着像坏的」到真的能用

- **修好面板读不到会话内容**（0.2.0 起最影响体感的问题）。内核把消息图从会话快照搬到了客户端组装层，插件还按旧位置取——所以「发送后有反馈、面板却永远是空态」。现在改从官方 ChatView 同源的位置取图，写作伙伴的回复、历史、工具活动都会正常渲染出来。实测：真回复 164–213 字进面板，助手套件 6/6。
- **伙伴现在知道你在写什么**：每次发送会自动附上「作品 / 正在写的稿 / 光标位置 / 有无未保存 / 今日净增与目标 / 成稿检查结果 / 当前段落」——这段只给模型看，面板里你看到的仍然是自己敲的那句话。
- **实时文本体检**（本地毫秒级、不联网）：长句、段落过长、程度副词堆太多、「的」堆叠、句内重复词、引号不成对、标点连打、空行过多——都会连同原文位置与建议一起报出来。
- **老会话「历史加载失败」修好了**：0.1.7 时代写的转录里有一个 0.2.0 已废弃的字段，会让整条历史被判死。已对你机器上的 27 条会话做了修复（修复前逐文件备份、整体另存一份，被裁内容可整段找回）。
- **文字工具**：输入上限 12000 → 24000 字、输出 2048 → 4096 tokens；超过上限时**明确告诉你只处理了前 N 字**，不再悄悄截断。
- **找资料**：超时 4 秒 → 8 秒、多一条备用搜索引擎、多条查询并行；联网失败不再假装「没查到」，会直说这次没查成。
- **伙伴能读网页原文了**（此前只能拿搜索摘要）。
- **项目备忘写满不再永久卡死**：到上限时自动把最旧的一段归档到 `state/backups/` 再继续，已确认的设定不受影响。

## 写作台：章节之家 + 档案上顶栏

- 左栏作品下面**只放章节**了：空项目显示「还没有章节 · 写第一章」，有章节时尾部有「＋ 新章节」（自动按最大章号 +1 建 `第N章-v1.md` 并打开）。人物/世界与设定/故事规划这类资料不再混在作品下面。
- **「档案」升级为顶栏图标**，点开是当前作品的档案窗口；项目操作行只剩「成书」和「添加资料」，后者收成内容宽、不再撑满整行，资料添齐的项目不再出现空下拉。
- 库根的散落 `.md`（「独立文稿」桶）不再占作品导航，只归文件视图与搜索管；顺带修掉大纲视图对它的报错。
- 一轮轻动效（120–180ms 浅位移淡入），系统开启「减少动态效果」时全部关停。

## 验收

- 升级保留全部数据（文稿/会话/设置）。macOS 提供未签名的 Apple Silicon（arm64）DMG。
