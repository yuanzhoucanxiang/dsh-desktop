# DeepSeek Harness Desktop 0.1.56

修两个你报的问题。

- **档案打不开**：顶栏的档案图标在「认不出当前是哪个作品」时会变成**灰按钮**，点了当然没反应。现在它会跨全部库根去找当前文稿所属的作品（此前只在当前库根里找，稿件属于别的库根就找不到），路径大小写/斜杠差异也不会再影响匹配；库里只有一个作品时直接用它；实在定位不到也保持可点，点一下会告诉你「先打开一篇稿件」。

- **切换工作区后写作助手起不来（面板显示「协调服务不可用」）**：写作用的内核侧有两条路由对"这是哪个作品"判断不一致——「写作伙伴」这条允许没有 `project.md` 的工作区（用工作区自己当身份），「协调」那条却认为它不是作品，直接拒绝，于是伙伴建立会话时协调失败、面板就报协调服务不可用。现在两条路由（以及备忘/草稿等按作品分桶的能力）统一用同一套判定：能认出作品就用作品，认不出就用该文件夹本身。实测：在没有 `project.md` 的工作区上，伙伴绑定与协调都通过（修复前协调直接 400）。

升级保留全部数据。macOS 提供未签名的 Apple Silicon（arm64）DMG。
