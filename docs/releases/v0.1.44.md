# DeepSeek Harness Desktop 0.1.44

本版移除外壳自带的「审阅」侧边栏，审阅体验由内置的 dsh-better-sidebar 插件承担；并修复了内置插件在部分升级环境里缺失的问题。

- **移除外壳审阅侧栏**：原右侧「修改审阅」面板不再出现；窗口标题与托盘的「运行中」提示照常工作。
- **dsh-better-sidebar 自动就位**：升级时会按安装包内置清单自动补齐缺失的内置插件（含 dsh-better-sidebar 0.15.2）；你手动卸载或禁用的插件不会被顶回来。
- **内置插件自愈**：插件已登记加载但文件缺失/损坏（历史悬空链接类问题）时，启动会自动用安装包里的完整包替换，不再导致整页不可用或功能悄悄消失。

使用说明：右下角若出现内核断连浮层，「重启内核」即可。macOS 提供未签名的 Apple Silicon（arm64）DMG。
