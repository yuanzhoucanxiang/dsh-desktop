# DeepSeek Harness Desktop 0.1.43

设置里新增「外观」页，可以自定义应用图标；同时本版起 Windows 安装包的应用图标恢复为正确的鲸鱼图标。

- **应用图标自定义**：内置「默认 · 鲸鱼」与「看板娘」两个预设，也可选择任意 PNG / ICO 文件。
- 窗口与任务栏图标**即时生效**；桌面、开始菜单、任务栏固定的快捷方式图标会同步改写。
- 选择会记住：安装或更新重建快捷方式后，应用启动时自动重新指回你选的图标。
- 边界说明：exe 内嵌图标由安装包决定（本版已恢复鲸鱼）；任务栏已固定的图标有系统缓存，可能需要取消固定再重新固定才会刷新；托盘是独立的主题色状态指示，不随此设置变化。

使用说明：外观设置在「设置 → 外观」。升级到本版后，之前的版本会通过自动更新拿到正确的安装包与全部既有修复。macOS 提供未签名的 Apple Silicon（arm64）DMG。
