# DeepSeek Harness Desktop 0.1.57

本版把写作助手往前推了两步：**你点一下就继续**，以及**伙伴终于知道你写到第几章了**。

## 「点一下就继续」

上一版伙伴会问你问题，但你答了它也不动——查内核实现后确认：**等待中的提问，写作台客户端够不着**（那次等待被官方卡片拿着，卡片渲染在普通会话视图里、盖在写作浮层下面）。所以这版两条一起上：

- **提问改成定时模式（60 秒）**：过时限模型可以先往下走，你的作答会作为「后补消息」送到。提问卡在你点完之后如果还没被内核收走，会**每 3 秒自动补交**（最多 135 秒），点一次就一定生效。
- **文本选项通道**：伙伴现在可以把选项直接写成按钮（`【选择】` 约定，最多五条），你点一下就是一次普通发言——模型本来就没被阻塞，所以立刻继续。判据宁可漏不可错：正文里本来就有的普通列表不会被误认成按钮。

## 伙伴有了「章节感」

以前伙伴只知道你在写哪篇稿、光标在哪、有什么体检问题；现在每次发言它还会收到：**第几章／共几章、上一章和下一章、各自的章末钩子、还有几条伏笔没兑现、这一章里谁在场、大纲里对应哪条、本章成稿检查是否达标**。这些都是从你作品里已有的结构读出来的（`outline/`、`draft/`、`bible/characters.md`），**没有章节结构就一个字都不注入**，不会编造；你在编辑器里改了还没保存的内容也算数。

于是可以直接问它：「这一章的钩子够不够？」「上一章埋的钟声该收了没有？」——它不用你再复述背景。

## 验收

全链 `verify:writing-quick` 绿（含冷启动、真包一致性、hardening 92/0、写作门禁 7/7、新增 `test:chapter-context` 14/14 与 `test:writing-choices` 22/22）。升级保留全部数据。macOS 提供未签名的 Apple Silicon（arm64）DMG。
