# DeepSeek Harness Desktop 0.1.52

本版把内置内核升级到官方 0.2.0 版本线（**0.1.7-rc.2 → 0.2.0-rc.2**，与官方桌面版同款），并按我们自己的升级手册走完了完整适格验收后才采纳。

- **内核 0.2.0-rc.2**：跟上了官方的 0.2.0 主线（此前我们停在 0.1.7）。升级前先做了只读适格验收：接触面契约 18 项全绿（运行时布局、启动行与一次性令牌、鉴权链、插件声明、设计令牌、DOM 锚点、渲染不变量），插件实测与写作模式全链路在候选内核上原样通过，才做采纳动作。
- **插件生态无需换版**：主题面板（palis 0.5.14）、侧边栏（better-sidebar 0.21.1）、dsh-pet 0.1.4 在 0.2.0 上实测加载与呈现正常；写作模式的会话/工作区/预设/草稿接口在 0.2.0 全部保留，不需要改适配层。
- **验收**：全链 604 项断言 0 非零（含真实内核的 Electron 端到端：写作 UI、会话、选区引用、主题、书架/档案、设置页）；打包与冷启动验收按发布流程执行。

使用说明：升级会保留全部数据（文稿/会话/设置）。macOS 提供未签名的 Apple Silicon（arm64）DMG。
