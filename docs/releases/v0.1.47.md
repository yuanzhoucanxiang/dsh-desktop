# DeepSeek Harness Desktop 0.1.47

本版是「写作模式」的一轮大更新：码字激励、编辑器基本功、AI 改稿回路与章节看板四条线一起补齐。

- **码字统计与日更目标**：保存后按作品记账（打开旧稿只播种基线，不会把整章存量算成今天写的；大删减不倒扣）；状态条显示「今日净增」，检查页新增码字区——今日大数、连续天数、近 14 天柱条、可编辑的日更目标（达标打勾）。
- **编辑器查找/替换**：Ctrl+F 呼出，计数 n/m、上一个/下一个、替换、全部替换；Esc 只关查找栏、不退写作台。
- **改稿 diff 回路**：文字工具「替换选区」不再一步覆写——先出「改稿预览」（原文 vs 建议稿行级 diff），采纳才落稿、丢弃原稿不动；预览期间继续打字有错位重定位兜底。
- **专注深化**：顶栏新增「海明威」开关（禁退格/删除/剪切，初稿只往前写；拼音输入不受影响）与「打字机」开关（光标行保持一屏中部）。
- **伙伴回复可跳回**：写作伙伴提到作品内文稿时用 [[文件名]] 标注，点击即跳到那篇稿（只在你的库内解析，编造的文件名不会打开任何东西）；参考预览新增「正文提及」徽标，正文里提到的设定一眼可见。
- **章节卡片看板**：文档库新增「大纲」视图——每章当前版一张卡（字数、门禁角标、章末钩子），**拖拽卡片即可调整章节顺序**（重命名事务落实：原稿内容不动、历史版本跟随、失败自动回滚）。

使用说明：升级会保留全部数据（文稿/会话/设置）。macOS 提供未签名的 Apple Silicon（arm64）DMG。
