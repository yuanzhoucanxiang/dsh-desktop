# DeepSeek Harness Desktop 0.1.53

本版集中修写作模式在**官方 0.2.0 桌面版**上暴露出来的一批问题，并补上「工作区可以直接在电脑里选文件夹」。

- **工作区（库根）可以点着选了**：设置 →「写作模式」→「工作区（库根）」点「浏览…」。在官方桌面版里打开的就是**系统自带的文件夹对话框**（与官方「添加工作区」用的是同一个，可新建文件夹），选中即成为库根并切为当前库根；自研壳与浏览器环境没有那座原生桥，自动退回**内置文件夹浏览**（磁盘与主目录/桌面/文档快捷入口、逐级点进、上一级、粘贴路径直达、已在库中的会标出来），按 Esc 取消不会改动任何设置。此前只能手打盘符。
- **不再和官方顶栏打架**：工作台按官方契约的顶部让位变量定位（Windows 40px / macOS 48px），顶栏右侧留出原生窗控区，最小化/最大化/关闭按钮不再压住工作台内容。
- **入口收敛成一个图标**：原先「左下角整宽按钮 + 右下角浮钮」两处入口，现在统一为侧栏底部动作行里的一个 32×32 图标（窄轨折叠时同样居中）。
- **设置里能改工作区**：每条库根显示 默认 / 当前 / 路径不存在 徽标、作品数与「设为默认 / 切到此库 / 移除」；「设为默认」同时切为当前库根。
- **修「一些按钮点了没反应」**：「辅助 ▾」菜单原先会盖住右侧 AI 面板的标签并自己吃掉点击，现在菜单容器对命中透明、点空白处直接落到下面的按钮上、选完自动收起。
- **写作助手发送后不再毫无反应**：会话悬空自愈改成自排队定时器，并在重挂流程里显式打开官方会话（限时 8 秒）。同场景实测：此前点发送只有草稿被清空、界面毫无变化；现在会进入「正在回应…」，且内核侧确实跑完（转录里用户消息、助手回复、工具调用齐全）。

已知问题（本版**未**修复，如实说明）：写作助手的**面板仍然渲染不出历史与回复**——0.2.0 的会话「chat 图」插件还没接上，面板只能显示空态；另外用 0.1.7 时代内核写的老会话（转录里带已废弃的 `origin` 成员）会被 0.2.0 的迁移器拒绝，表现为「历史加载失败」。两者都在继续追。

使用说明：升级保留全部数据（文稿/会话/设置）。macOS 提供未签名的 Apple Silicon（arm64）DMG。
