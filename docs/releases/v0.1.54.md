# DeepSeek Harness Desktop 0.1.54

本版是写作模式的**前端整合收口**：主界面回到「纯粹的写作」，按钮与资料各归其位。

- **顶栏减负**：删掉「库 ⟩」「AI」两个开关。左右栏的收起/展开全部就地完成——收起后身体边缘留竖排 rail（左「文档库」、右「AI」），展开后面板头有折钮。顶栏只剩：库选择 / 专注 / 辅助▾ / 保存 / 退出写作。
- **文字工具收进输入框**：润色/续写/大纲/压缩/扩写/找资料/灵感七个动作，从独立抽屉收进写作伙伴输入框旁的「✦」小图标（类似 Codex 的「+」）。点选后工具进入待运行状态（输入框上方出现「✦ 润色 ×」标记），可以**再补一句要求**（比如「语气再轻一点」），Enter 运行、Esc 或 × 取消。运行结果出现在输入框正上方，插入文末/替换选区/发送到会话照旧。
- **左栏默认只见章节**：打开一个项目，直列的就是各章正文；作品概览、人物、世界与设定、故事规划、创作跟踪收进「资料与设定 · N」折叠容器（搜索或正在编辑其中文件时自动展开）。不再一堆资料与章节抢同一层。
- **左栏视觉分层**：章节是主角（列表里唯一大号字），项目名是中黑锚点，分组标签与「档案/成书/添加资料」降为灰色小字，视图切换与搜索框退成安静的控件。主次一眼可辨。
- 顺手可读性：「＋ 添加人物、设定或规划…」瘦身成「＋ 添加资料」。

已知问题仍未修复（沿自上版，如实说明）：写作助手面板暂时渲染不出历史与回复（官方 0.2.0 的会话 chat 图尚未接上）；0.1.7 时代内核写的老会话可能被 0.2.0 迁移器拒绝（「历史加载失败」）。两者都在继续追。

使用说明：升级保留全部数据（文稿/会话/设置）。macOS 提供未签名的 Apple Silicon（arm64）DMG。
