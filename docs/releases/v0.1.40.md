# DeepSeek Harness Desktop 0.1.40

写作伙伴更易读，项目备忘保留准确来源与多行内容。

- **回复排版**：右侧写作伙伴支持标题、粗体、引用、列表、表格、代码和网页链接。长代码与表格在侧栏内滚动，作者输入保持原文。
- **候选来源修复**：从助手消息“记为候选”后，即使编辑、确认，也保留原助手消息和会话来源，不再误记为作者提出。
- **多行备忘**：新增与编辑备忘支持多行，保留候选文字中的段落与换行。
- **构建与回归**：修复 Windows 换行转换导致的构建校验误失败，新增流式回复、窄栏、长历史与候选保存测试。

已完成真实模型的讨论、设定确认/修改/撤回、另存改稿三场景，以及同一内核下两个真实窗口的草稿恢复和会话关联验证。
保留 Harness 原生模型、工具和权限流程，没有增加固定字数、轮数或强制任务模板。

macOS 包为未签名 Apple Silicon（arm64）DMG；macOS 实机、NSIS 隔离安装、受控离线及长上下文压缩后续聊尚未验收。
