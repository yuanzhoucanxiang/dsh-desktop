# DeepSeek Harness Desktop 0.1.38

写作模式新增独立的「写作伙伴」界面，可以围绕作品持续交流，并按需使用 Harness 的模型和工具。

- 右栏改为专用对话记录、轻量输入框与可移除稿件/选区引用；文字工具单独切换。
- 按项目保存会话关联，保留原生模型、工具、授权和上下文管理；交流不强制阶段、轮数或字数。
- 发送失败保留草稿，发送期间的新输入不被擦除；支持停止、消息排队和中文输入法防误发送。
- 加强外部改稿冲突保护与历史版本保护；补齐项目模板、资料入口和写作回归测试。
- 策划案 v0.5、接口契约、工作日志及验收记录已同步纳入仓库。

使用说明：授权、复杂提问、附件、斜杠指令和模型调整可进入同一完整会话处理。未发送引用暂存在当前页面；消息正文目前按纯文本显示。真实模型多轮自然度、长上下文设定保持和真实工具改稿仍待进一步体验验收。

Windows 提供安装包与自动更新清单。macOS 提供未签名的 Apple Silicon（arm64）DMG。
