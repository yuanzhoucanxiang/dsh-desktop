# DeepSeek Harness Desktop 0.1.48

本版修掉一个 0.1.45 以来一直存在的老毛病，外加写作模式一轮大更新。

- **修复：主界面永久「重新连接中」**。此前版本的状态栏连接指示器会一直红着转圈——病灶是页面直连内核的 WebSocket 握手被内核安全栅栏误判为跨域（自定义协议页面的 Origin 与内核回环地址天然不同形），握手恒被拒、无限重试。聊天等核心功能其实一直正常（它们走外壳转发通道），现在外壳在网络层把这条 WS 直连也纳入同一转发口径，连接一次成功、指示器恢复正常。顺带治好了同类病灶的插件直连（如 better-sidebar 的终端/文件监听）。
- **修复：自定义协议下自家页面被误判跨域**。此前档案窗口点作品名跳不动、部分界面事件静默不发，都是同一比较器把 `dsh-app://` 地址的 origin 读成 `"null"` 所致；现已按平台事实修正。
- **写作台前端重做**：结构收口（主组件 1853→1149 行，六个纯 props 子组件）+ 视觉令牌层（字号/圆角/间距/字重归档）+ 一批糙点修复（三视图选中态、下拉溢出、勾选框跟随主题色等）；退出写作台时保存失败现在会明确提示而不是静默留下。
- **作品档案**：写作台项目条上的「档案」按钮，一页汇总已确认设定、每章进度、时间与伏笔、资料区；档案可**导出为一页自包含 HTML**（写进作品根目录、绝不覆盖原稿），也可开**独立窗口**翻阅（页内目录、篇内小目录、多部作品间一键切换）。

使用说明：升级会保留全部数据（文稿/会话/设置）。macOS 提供未签名的 Apple Silicon（arm64）DMG。
