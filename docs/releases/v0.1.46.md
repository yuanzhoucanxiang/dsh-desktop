# DeepSeek Harness Desktop 0.1.46

本版让内置「写作模式」在 0.1.7 新内核上完整恢复，并带来两轮新能力：导出成书，以及一整轮"状态都会说话"的体验收口。

- **写作伙伴恢复**：修复 v0.1.45 升级新内核后「写作伙伴会话不可用」的问题——写作助手预设随插件自动注册，建会话改为绑定作品工作区，聚焦与草稿跟随新内核接口；旧内核环境同样兼容（双栈自适应）。
- **导出成书**：作品头部新增「成书」——默认勾选每章最新版（历史版本自动略过），按目录树顺序拼成整本书稿，写入 `书名-vN.md`（独占命名，永不覆盖原稿）；Markdown 自动带书头（书名/篇数/字数），可选每章前补标题；Fountain 稿按题页分页。
- **右栏三区**：写作伙伴 / 文字工具 / 检查三区整合；伙伴顶部新增可折叠「写作会话」列表，点击即切换同一作品下的会话；「另存为新版」归拢到文档名旁的版本条。
- **状态都会说话**：内核能力缺口在伙伴面板顶部直接说明「缺什么、还能做什么、想法会不会丢」，不再只有灰按钮；连不上时输入框仍可写下想法，恢复后直接发送；保存/读取失败在稿面下方常驻显示并给出「重试保存 / 另存新版」出路；专注模式下点「AI」退出专注并唤回右栏（原先是死键）。
- **快捷键提示统一**：Esc 退出 · Ctrl+S 保存 · Ctrl+Shift+S 另存新版 · Ctrl+Shift+W 开关写作台（此前两处提示互相矛盾）。

使用说明：升级会保留全部数据（文稿/会话/设置）。macOS 提供未签名的 Apple Silicon（arm64）DMG。
