# DeepSeek Harness Desktop 0.1.39

写作模式完成架构整改与两轮独立复核：native 接触面收敛、会话创建协调、作者可控记忆与当轮上下文、
发布门禁加严。桌面外壳侧同时修好了打包依赖漏发与主题冒烟的过时断言。

- **Native 接触面收敛**：会话查找/创建/绑定/发送全部经 `adapters/harness` 的 adapter；界面不再直接读
  原生 `chat.nodes/order`，改为消费 adapter 投影，未知节点保留可见摘要与完整会话入口。
- **发送受理三态**：明确拒绝（保留正文，可改完再发）· 已受理 · 无法确认（保留正文，先核对原生回合，
  **不自动重发**）。只有拿到内核可证明的本轮标识才算受理，文本相似不再作为依据。
- **跨窗口会话创建协调**：进程内共用创建 Promise，跨进程由持久协调记录仲裁（预留 → 创建中 → 已绑定 /
  不确定），过期 token 不能改写新绑定；创建结果无法确认时保持"不确定"并保留已知标识，
  **不会悄悄另建会话**；会话被删除时给恢复入口，不静默切到新空会话。
- **作者可控的项目备忘**：手工新增 / 助手消息"记为候选"（默认候选，不自动当事实）/ 编辑 / 确认（记录操作者）/
  撤回 / 问题已解决 / 历史对照与恢复（产生新版本，不回退版本号）。作品目录隔离，坏文件保留原件并给诊断。
- **当轮上下文**：输入区显示"参考项目备忘 · N 条"，可展开逐条勾选/排除/优先；只自动参考**已确认**的设定与偏好，
  待定问题要勾选才带入并单独标识；自动部分有 6000 字符预算（作者正文与显式引用的稿件不受限）；
  每次发送重新读取备忘，本轮请求一旦准备即冻结。
- **引用身份**：来源（路径/版本/选区）与正文分开，未保存内容带快照指纹；源稿改过会提示"引用来自旧快照"并支持重新引用；
  旧格式引用原样兼容。其他窗口的草稿只作为候选列出（带窗口与时间），采用前会先为当前草稿留一份可恢复副本。
- **打包与门禁**：内置插件按 `runtime-manifest.json` 清单发布（测试与源码不再进用户机器）；外壳主进程依赖
  纳入发布集合并逐字节校验；新增架构/适配/备忘/上下文/打包/冷启动/升级/复核探针等一键入口，
  发布门禁缺件即失败。
- **主题**：整体皮肤开启/关闭与内核页联动照常；主题冒烟改为验证真实契约（注入样式表与调色、关闭后移除）。

使用说明：授权、复杂提问、附件、斜杠指令和模型调整仍进入同一完整会话处理。真实模型多轮自然度、长上下文设定
保持与真实工具改稿仍待体验验收；macOS 安装包为未签名 Apple Silicon（arm64）DMG。
