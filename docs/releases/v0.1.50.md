# DeepSeek Harness Desktop 0.1.50

本版把「AI 在场」和「数据安全网」两块补上，同时完成写作模式服务端的一轮结构治理。

- **AI 更「在场」**：写作伙伴的设定注入范围从「聊天框那几个字」扩大到「消息 + 你引用的稿件/选区全文」——引用整章问「这段节奏对不对」时，章里提到的已确认设定（人物、禁令、势力）会自动排到注入最前，不再靠运气。
- **每日快照（安全网）**：每次保存成功后自动给作品拍一份当日快照（zip），存在应用数据目录的 `writing-backups/` 下，每个作品每天一份、自动清理只留最近 14 份。只读你的作品、只在作品目录之外写备份，失败也绝不影响保存——「一年心血在一个目录里」从此有兜底。
- **服务端结构治理**（内部重构，行为不变）：写作模式的 host 从 1400 行的单文件拆成按域组织（配置/文档/项目/备忘/会话五个域 + 公共 HTTP 层），错误守卫统一收口；期间门禁三次拦住发布级事故（打包白名单漏配两处、模块登记遗漏一处），全部在合并前修复。
- 本版同时带上 0.1.49 之后入库的全部内容：作品档案多页站点、写作台降噪、纯写作第一屏的细节收尾。

使用说明：升级会保留全部数据（文稿/会话/设置）。macOS 提供未签名的 Apple Silicon（arm64）DMG。
