# DeepSeek Harness Desktop v0.1.41

写作模式新增世界观讨论整理：与写作伙伴自由聊，选择要整理的消息，生成候选；编辑并确认后成为项目设定。无需固定创作步骤。

- 支持候选保存、已确认设定修订、撤回与历史查看；未确认的修改不覆盖生效版本。
- 自动参考已确认的结论和边界，长说明保留在设定中，避免挤占默认上下文。
- 生成可读的世界观整理稿；手工修改发生冲突时可查看差异、保留手稿副本后重建。
- 修复整理发送、候选来源与串写、幂等重试、旧数据迁移、投影并发恢复和备份路径越界。
- 新建项目拒绝非空目录覆盖及非法目录名；修复世界观面板与打包依赖缺失。

验收：真实模型五类故事场景、两个真实窗口冲突与解决、完整工程门禁及打包冷启动。具体证据见 docs/audits/writing-world-settings/2026-09-20/。

边界：候选本地编辑仅验证同窗口刷新恢复；NSIS隔离安装、macOS实机、受控离线、项目目录移动与压缩后连续性尚未验收。macOS产物未签名。未替用户安装或关闭现有桌面。
