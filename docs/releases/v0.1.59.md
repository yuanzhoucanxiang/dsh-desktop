# DeepSeek Harness Desktop 0.1.59

这一版两条线：**自研壳的数据终于和官方桌面版分开了**，以及**写作助手的三个真缺陷被真机探针抓出来并修掉**。

## 数据隔离：默认私有数据目录

此前两个桌面版都解析到 `~/.dsh`，所以会话记录互相可见。现在本外壳默认用私有 `~/.dsh-desktop`：**首次启动把共用 home 只读复制一份**（源目录一个字节都不动），此后各写各的。迁移幂等、失败下次续跑、链接按链接重建（junction 不 deref），profile 清单里指向旧 home 的绝对路径同步重指。设置面板新增**「数据」页**显示路径与模式。实测：dev 与打包版冒烟均 `SMOKE_OK`，306 MB / 2062 文件 / 793 链接、4 秒完成，源目录零改动。

## 写作助手：三个真缺陷（都是真机探针抓出来的）

1. **作者看得见系统文字**：插件替作者拼进 prompt 的「写作模式状态」「项目备忘」块，内核会当作**作者消息**存进转录——作者在伙伴面板里看到一整段系统文字。现在投影层渲染前剥掉它们，只留作者自己写的话（官方完整会话视图仍显示原文，属已知限制）。
2. **世界观整理解析不了真模型的回复**：模型常把 JSON 夹在解释里且不带围栏，原解析器一律判失败，于是「整理为设定」一条候选都落不了库。现在会从自由文本里抽第一个**配对完整**的 JSON 对象。**真机 E2E 7/7 通过**：真模型对话 → 勾选消息 → 整理 → 新增候选，console 零报错。
3. **实时体检看不见**：状态条现在有「体检 ✓ / 体检 N 处」芯片，**点开**列出每条提示（带原文片段），**点一条光标直接跳到正文那一处**；本地算、400ms 防抖。

## 还有
