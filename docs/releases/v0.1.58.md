# DeepSeek Harness Desktop 0.1.58

小版本，两件事：**写作时看得见的体检**，以及一份**先量后改的性能结论**。

## 状态条上的实时体检

写作台底部状态条末尾多了一个芯片：

- 没问题 → 「体检 ✓」（灰色，不抢读）
- 有问题 → 「体检 N 处」（警示色）
- **点开**：列出每一条提示（提示语 + 原文片段），**点其中一条光标直接跳到正文那一处**，选区正好落在问题上，接着改就行
- 干净正文时写明「没有明显问题：长句、副词密度、「的」堆叠、引号开合这些都没踩到」

它是**本地算的**（纯函数、零网络、400ms 防抖），长稿也不会在每次敲键时算一遍；同一份结果本来就会随消息发给写作伙伴——现在你自己也看得见了。

## 性能：量过了，不需要动

新增基准脚本量了三条热路径（真实写作库，各跑 5 次取最好）：

| 路径 | 触发时机 | 实测 |
|---|---|---|
| 全库扫描 `scanTree` | 每次库刷新 / 保存后 | **2.4 ms** |
| 章节上下文 `chapterContext` | 每次换稿 | **0.2 ms** |
| 实时体检 `textHealth` | 每次敲键后 400ms 防抖 | **1.4 ms**（2 万字正文） |

都在毫秒级以下，所以这一版**没有做任何性能改动**——数据记了档，等作品规模上去（数千文件量级）再按计划加缓存，而不是现在拍脑袋优化。

## 验收

全链 `verify:writing-quick` 绿（含冷启动、真包一致性、hardening 92/0、写作门禁 7/7、体检芯片可开可收断言）。升级保留全部数据。macOS 提供未签名的 Apple Silicon（arm64）DMG。
