# DeepSeek Harness Desktop 0.1.45

本版把内置内核从 0.1.1-rc.1 升级到官方 0.1.7-rc.2（追平 6 个 rc 周期），并把窗口加载架构对齐官方桌面端（本地直出前端 + 转发内核），同时更新了跟随内核的插件与安全网。

- **内核 0.1.7-rc.2**：会话、工作区、插件生态的官方新能力随内核到位；契约探针、渲染不变量、插件实测全部通过后才采纳。
- **加载更稳、更省**：界面资源由外壳本地直出（重复启动少读盘），内核端口与一次性令牌不再出现在页面地址里；插件 API 经统一转发，第三方插件的终端/文件监听在新架构下照常工作。
- **升级保护**：老环境升级内核时，外壳自动把 profile 里的内核包链接对齐到新运行时（幂等），不再出现升级后启动失败。
- **插件更新**：dsh-better-sidebar 0.21.1（新内核必需）、主题面板 0.5.14（你的主题设置原样保留）；升级首启自动补齐缺失插件。
- 已知变化：启动行的 URL 不再带 token（安全面收紧）；旧方式可用环境变量 `DSH_DESKTOP_SCHEME=0` 回退。

使用说明：升级会保留全部数据（文稿/会话/设置）。macOS 提供未签名的 Apple Silicon（arm64）DMG。
