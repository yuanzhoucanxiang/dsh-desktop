# DeepSeek Harness Desktop 0.1.49

本版三件事：写作台开屏更纯粹、界面更安静、作品档案变成真正的多页站点。

- **纯写作第一屏**：打开写作台默认只有稿纸——右侧伙伴/工具/检查与左侧文库都收起，需要时点顶栏「库 ⟩」「AI」召唤；没有打开文稿时是一张真正的空页（「一张空页。」+「新建一篇 / 从库里打开」），空页唤起的文库是「借来的」，文稿一开就自动收回稿纸；退出再进，面板开合状态保留。
- **作品档案 wiki 站点化**：档案窗口从一页长滚动升级为多页站点——首页是入口（前提、码字统计、四区入口卡），设定/进度/时间与伏笔/资料各成一页，资料按篇成页、篇内有小节就逐节一页（「每个人物一页」由此落地），每章正文一页带上下章。**导出仍是单文件自包含快照**（打印/分享用），站点与导出共用同一套渲染。
- **一轮降噪**：档案页不再摆整张空模板表、空字段行不渲染、目录粘性常驻、进度区补 14 天码字柱条；写作台文字工具摘掉伪开关高亮、状态条分隔归一、版本号过多时折叠、成书面板与稿纸同宽不再左右跳。
- **随 0.1.48 的修复一并带上**：主界面永久「重新连接中」的根治（scheme 模式 WS 握手剥 Origin/代注 Cookie）已在 0.1.48 发布，本版无新增外壳改动。

使用说明：升级会保留全部数据（文稿/会话/设置）。macOS 提供未签名的 Apple Silicon（arm64）DMG。
