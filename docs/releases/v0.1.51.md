# DeepSeek Harness Desktop 0.1.51

本版修两个问题：内核设置页读不出数据、外壳启动时的一处无谓改写。

- **修复「设置 → 模型」页一直显示加载失败**：在我们的窗口里，这一页此前恒显「加载提供商目录失败」（点重试也无效）。根因不在网络，而在环境判定：页面跑在应用自注册的协议下，内核把它当成"远程浏览器"，于是把设置持久化降级为进程内临时存储——读取设置的门面在这种模式下从不加载，这一页因此永远读不到提供商目录。修复后该页恢复正常；连带的好处是**内核设置页里的修改从此正常持久化**（此前重启即丢）。

  顺带说明影响范围：写作、对话、文稿、导出等一切功能不受此问题影响；受影响的只有内核自带设置页里的持久化。我们在真实窗口里加了回归断言，并用负向对照逐字复现了原报错来证明断言有效。

- **修复启动时的一处无用改写**：外壳为内核包维护链接对齐时，把一批版本号自成体系的框架包（cordis、cosmokit、schemastery 等）误判为"需要对齐"，每次启动都重写一遍链接——目标其实没变，纯属噪声。现在这批包会被正确识别为"已在位"，启动不再做无用改写（幂等性回归测试已补）。

使用说明：升级会保留全部数据（文稿/会话/设置）。macOS 提供未签名的 Apple Silicon（arm64）DMG。
