# 工具台主屏 · 互动原型（v2.2，2026-10-12）

用户拍板的工作方式：**先做 HTML 互动原型，手感定了再落正式实现**。
本目录是纯静态、零依赖的原型（单文件内联全部样式与脚本），不与仓库构建/门禁挂钩。

## 跑

```bash
npm run dev            # 零依赖静态服务器，默认 127.0.0.1:7100；--port/--host 可改
# 或者直接双击 index.html / strip.html（file:// 也能跑，无任何外部资源）
```

注意：本机部分端口在 Windows 排除段里（如 7106 会 EACCES），换一个即可。

## 两套设想（两个页面，互相跳转）

### v1 · 主屏瓷砖格（`index.html`）

进入工具台 = 全屏主屏：左列 agent 对话 + 右侧模式瓷砖格（写作 / GIR 生图 / 导演-规划中）。
**这版的正式实现已经落地**（`plugin/workbench`，L2 第二刀，2026-10-11），原型里超出正式版的部分：
真聊天瓷砖（转录 + 输入框）、写作/生图的真内容窗口瓷砖、瓷砖里的「✂ 把选段送去生图」直送钮。

### v2.2 · 长条对话窗 + 模式拼接（`strip.html`，用户 2026-10-12 的设想）

启用工具台模式后，**整个桌面版窗口收成一条「手机微信式」长条窗**（主 agent = 工作台）：

- 顶栏窄条：← 返回工作区选择 · ⚙ 设置 · — 最小化 · ⎋ 退出工作台模式 · ✕ 关闭界面；
- 中间对话 + 底部输入框（左侧「+」上传文件和更多工具）+ 输入框下一窄条状态（⚡ token 速度 ·
  缓存命中 · 上下文用量——发消息会流式回复、指标跟着动）；
- **最小化 → 右下角小长条**：只留 返回默认界面 / 退出 / 关闭 + 同一条状态数据；
- **窗外就是电脑桌面**——没拼接时屏幕上只有这一条长条窗，没有什么预留的纯色「舞台背景」
  （原型里用壁纸 + 桌面图标示意）；
- **模式拼接（v2.2 定稿的规则）**：鼠标放到长条窗**右缘**——已有模式时，那里就是长条窗与模式窗口的
  **拼合处**——可启用的模式图标**朝窗外的桌面扇形展开**（不压窗口；以接缝为轴心、中间那颗顶到最外）；
  点一个，**新模式像细胞分裂一样从接缝展开**：
  - 右侧：新界面**贴着长条窗**插入，把既有模式界面依次往外顶（左缘可拖拽调宽 300–760px）；
  - 左侧：新模式的**子 agent 对话拼到最外边**（既有子对话的更左边）——两侧位置恰好镜像；
  - 各模式与主 agent 相互独立、可同时拼接同时推进；主 agent 对话里出**统筹卡**跟踪各模式任务，
    子 agent 完成时主 agent 汇总；收起面板反向塌缩。

原型 ↔ 正式实现的落差（别当成已有）：

| 原型里的东西 | 正式实现的层面 |
|---|---|
| 窗口变成长条/小条（变形、还原） | **壳层**（Electron 主进程管窗口尺寸/位置/chrome），不是插件层能做 |
| 右侧拼接的模式界面 | 需要模式交出「可嵌入视图」——比辅助坞重，对应 plan §9 的**真分屏**开放问题 |
| 左侧各模式独立的子 agent 对话 | **已查（2026-10-12）**：内核有多会话并行 + preset 原语（写作模式已在用）；「一个 Lead 统筹一队」的实验包 `dsh-experimental-agent-team`（信箱 + 任务 DAG + 实时投影，默认关闭、profile 开关启用）可用但不承诺稳定，且启用会禁掉普通 subagent 委派。统筹语义（谁是主、完成汇总、统筹卡）要工具台自己写 |
| token 速度 / 缓存命中 / 上下文窄条 | **已查：三条都有真数据源，不用改内核**。`sessionStats`（decodeTokens/decodeMs → tok/s）、`tokenUsage`（cacheReadTokens → 命中率）、`contextPressure`/`contextBreakdown`（上下文用量），统一走会话的 `projections` 快照 Store。官方 Web 聊天统计条就是同一套算法 |
| 面板拖拽调宽后「拼回」 | 壳层拼接几何（吸附/记忆宽度），原型只演示了调宽 |

## 踩坑（正式实现要带走的教训）

- **`hidden` 属性会被类里的 `display` 盖过**（2026-10-12 实锤翻车：strip.html 首屏被「界面已关闭」遮罩
  糊住，index.html 的模式占位层也一直压在主屏上）——UA 样式 `[hidden]{display:none}` 在优先级上输给
  作者样式里任何显式 `display`（如 `.closed{display:flex}`）。两页已在 reset 后加全局守卫
  `[hidden]{display:none!important}`。**正式实现同理**：关闭状态首选渲染 `null`（guide §5 既定规则）；
  若用 `hidden` 属性，必须带这条守卫，否则一个类名就能让"隐藏"失效。
- 验证方式留档：改完用 InAppBrowser 实测 `getComputedStyle`（#closedVeil / #mini / #modeOverlay 均
  `display:none`），不是只改不测；Kimi 预览服务（7105）直接按磁盘文件服务本目录，改完刷新即生效，
  不用重启。
