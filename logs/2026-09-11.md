## 〔123〕 写作模式：修「进不去」（Hooks 顺序）+ 踩坑写回策划案

#### 现象

用户反馈点「写作模式」进不去。源码 `node --check` 通过、host 可 import、profile 补丁仍挂
`writing-mode`——不是没加载，是 **overlay 组件渲染崩溃**。

#### 根因

`WritingModeApp` 在 `if (!active) return null` **之后**仍有 `react.useMemo`（版本系列）。
未激活时少跑一个 hook，激活时多跑 → React Rules of Hooks 违规 → 组件抛错；
浮钮在 active 时又被 `display:none`，用户既进不去也退不出。

#### 修复（`plugin/writing-mode/client.js`，已同步 profile + Programs）

1. 全部 hooks（含 `versionSeries` useMemo）挪到 early-return **之前**；`versionOf` 提到模块级。  
2. 打开模式时浮钮仍显示（「退出」，z-index 96），overlay 坏了可退出。  
3. `loadFile` 仅当服务器路径 ≠ 请求路径时 `setFilePath`，避免 effect 死循环。  
4. 清理重复的 `versionOf` / `docBasename` / `useMemo` 块。

#### 文档

- `E:\剧本\写作模式-策划案.md` 新增 **§13 踩坑与注意点**（Cordis inject、正式版 vs 源码、
  React Hooks、扫描去重、构建占用、与 writing-studio 协作、下轮修 bug 检查清单）。

#### 用户侧

- **Ctrl+R** 刷新页面即可（纯 client）。  
- 仍异常时：浮钮应能退出；把 DevTools 报错发来。

#### 下一步（用户指定）

**先修 bug**（见策划案 §13.6 清单），再继续功能。
