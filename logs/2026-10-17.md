## 预览 401：根因与修法（用户实报，2026-10-17）

用户："预览内核页面取回失败: 内核对 `/` 返回 401"。

**根因**：预览实例与别的实例**共用同一份私有数据**（默认 `~/.dsh-desktop` 的 token/端口状态），
后启动的实例换掉 token ⇒ 先起的那个页面再用旧 token 取回就被 401。**不是鉴权代码坏了**。

**修法**：预览一律带**独立 `DSH_DESKTOP_HOME`**（+ 独立 `DSH_DESKTOP_USER_DATA`，数据都放
`%TEMP%\dsh-preview\` 下）。实测（新实例）：页面渲染出工具台入口 ✓、内核 `ready at` ✓、
日志 `401 = false` ✓。

**我自己又踩一脚（如实记）**：PowerShell 里把变量命名成 `$home`（**只读自动变量 HOME**）⇒ 赋值失败，
随后 `$env:DSH_DESKTOP_HOME = $home` 把 HOME 设成了 `C:\Users\DL` ✗ ⇒ 内核往**用户主目录**写了
`profiles/ sessions/ storages/ .anonymous-user-id .credentials.yaml`（创建时间全是 16:24:46–51 = 我那次）。
已**先备份**到 `%TEMP%\dsh-wronghome-backup-20261017-162530` 再按创建时间删除；复核只剩 Codex 自己的
`.codex`（16:24:14 创建，不是我建的）。

**另一个过程坑**：第一版启动器脚本用 `spawn` 但**不 unref**、又故意不 kill 预览 ⇒ node 进程挂着不退出
⇒ 被当成后台任务常驻。改用 `spawn(..., { detached: true }); child.unref()`：启动器退出、预览留着。

**沉淀**：AGENTS 新增 **§2.3 预览实例必须带独立私有数据目录**（命令模板、\"验证取回成功别只看进程\"、
`$home` 只读变量的坑、启动器要 detached/unref）。

## G6 修好 + 流程探针跑通（提交 `4aa07e5` 探针 + `003fec9` 修复）

`shape`** ✗ —— 壳被**外部**改形态（「最小化小条」再切回来、程序化 `setWorkbenchShape`、别处入口）时，
