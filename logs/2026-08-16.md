- **坑 / 备注**：
  - **状态类名撞车**：初版用 `.mark.error` / `.status.error` 做错误态，而 `.error` 同时也是错误面板的类名——`.card > .error` 与 `.error` 规则会把 mark 和状态胶囊整块套成错误面板样式（宽高、边框、动画全被覆盖）。已改为独立的 `is-ready` / `is-error` 状态类，布局检查里加了 `#errorBox` 精确选择器防再犯。
  - **隐藏窗口动画冻结**：`show:false` 的 BrowserWindow 里 CSS 动画时间线会被节流（`backgroundThrottling:false` 也救不了部分动画），错误面板一直停在第 0 帧。测试工具改用「离屏可见窗口」（`show:true + x/y=-20000 + skipTaskbar + focusable:false`）后动画正常走完；应用本体不受影响（ready-to-show 才显示），且入场闸门让表现更可控。
  - **capturePage 物理像素**：`capturePage().toBitmap()` 输出物理像素，DOM 坐标是 CSS 像素，采样必须乘 `bitmap/inner` 的缩放比，否则区域采样全部落偏。
