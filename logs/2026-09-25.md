# 2026-09-25 · dsh-desktop

## 修复 Windows 发布包丢失应用图标（v0.1.42 资产已替换）

### 现象与根因

用户报告安装后的应用图标变成 Electron 默认图标。根因：自 v0.1.39 起，本地发布为绕开
electron-builder 在 packaging 阶段连 GitHub 下载 electron 的问题，构建配置里带了
`win: { signAndEditExecutable: false }`。这个开关跳过的不只是签名，还有**往 exe 写入图标与
版本信息的资源编辑步骤**——于是 0.1.39/0.1.40/0.1.41/0.1.42 的 Windows 包全部带着默认图标
（macOS dmg 由 GitHub Actions 用正常配置构建，不受影响；NSIS 安装器自身的图标由 makensis
编译时嵌入，也不受影响）。

### 修法

1. **重建 v0.1.42**（用户当前所在版本）：`git worktree add` 到 `v0.1.42` tag（ac00c15，
   不混入工作区里未发布的 hotkey 改动）→ node_modules 以 junction 复用主仓库 →
   `System32\tar` 打 runtime.tar.gz（runtime 自 8 月锁定未变，与 tag 内容一致）→
   `prepare-builtin-plugins.mjs` 产出内置插件树（pnpm 走本地 store；palis v0.5.13 起初
   下载失败、TEMP 缓存已被清理，重试后成功）→ 用 `win: { signExecutable: false }`
   **只跳过签名、保留图标/版本信息**重建 dir 包。
2. **验证**：提取新 exe 的关联图标为 PNG 与默认 electron.exe 对比（哈希不同），人工确认是
   鲸鱼 logo；`verify-writing-package --package` 在 worktree 内 8/8（含 app.asar 主进程模块
   与 tag 源码**逐字节一致**）；真包 `--smoke` → `SMOKE_OK`。NSIS + `gen-update-manifest.js`
   出 `latest.yml` 后覆盖上传 `setup.exe / .blockmap / latest.yml` 三个资产，远端 latest.yml
   的 sha512 与本机构建完全一致（`pA5yN3sA…`）。
3. **防复发**：`scripts/rebuild-package-tmp.mjs` 改为 `signExecutable: false` 并加注释说明
   两个开关的区别；本次提交不包含用户工作区里未提交的 `lib/hotkey.test.js` 改动。

### 用户侧操作

同版本不会触发自动更新（updater 比较 version 相等即跳过）：**到
<https://github.com/yuanzhoucanxiang/dsh-desktop/releases/tag/v0.1.42> 重新下载
`dsh-desktop-0.1.42-setup.exe` 再装一遍即可**（覆盖安装保留 userData/账号/会话）。
装过的旧版本（0.1.39–0.1.41）用户会经自动更新升到修复后的 0.1.42，无需单独处理。

### 坑

- Git Bash 下 `System32\tar.exe -C <带空格路径> runtime` 会把路径咬碎（`es\compiler\lib\mic`），
  必须经 PowerShell 调用（build.ps1 一直是对的）。
- 摘除 worktree 里的 node_modules junction 必须用"删链接本身"的方式
  （PowerShell `(Get-Item …).Delete()` 或 `rmdir`），`git worktree remove` 会递归删除目录、
  跟随 junction 把主仓库的 node_modules 内容一起删掉——先摘链接再 remove worktree。

## 设置 → 外观：应用图标自定义（含新「看板娘」预设）

需求：用户想在设置里自定义应用图标，并把工作区根的 `图标.png`（蓝发看板娘，1254×1254 RGB）作为可选之一。

### 能力边界（Windows）

- **能改**：窗口/任务栏图标（`win.setIcon`，即时生效）；桌面 / 公共桌面 / 开始菜单 / 公共开始菜单 /
  任务栏固定区的 .lnk 的 IconLocation（指到 userData 里生成的 .ico）。
- **改不了**：exe 内嵌图标（打包期资源编辑）——「默认」预设即 exe 内嵌鲸鱼；
  托盘是独立的「主题色鲸鱼」状态指示，设计上不随此设置变化（UI 里已说明）。

### 实现

- `lib/app-icon.js`（纯 Node 可测）：预设表、取值校验、**PNG 帧 ICO 容器封装器**
  （16→256 七档，nativeImage 负责缩放与编码）、快捷方式改写 PowerShell 脚本构建器
  （参数 base64 内嵌，杜绝引号注入；`-EncodedCommand` 执行）。
- `lib/app-icon.test.js` 7 项：ICO 目录项/偏移/256→0 编码、非法帧过滤、预设文件存在性、
  取值白名单、脚本 base64 还原语义、reset 语义、扫描范围。
- `main.js`：`settings.appIcon`（default/预设 key/custom）；四个窗口创建点换成动态图标；
  `shell:pick-app-icon`（设置窗口专属，文件选择）与 `shell:set-app-icon`（复制/生成/持久化/
  应用到窗口/改写快捷方式）；get-state 以 privileged 附带 `appIcon` 与缩略图（dataURL，
  对齐字段最小化原则）；启动时非默认则**重申快捷方式图标**（安装器/更新会重建 .lnk）。
- 设置 UI：新「外观」页——预设卡片（缩略图+选中态）、自定义 PNG/ICO 选择、恢复默认；
  CSP 为缩略图放开 `img-src data:`；UI 文案说明固定图标缓存与托盘不受影响。
- 资产：`build/icons/maiden.png`（用户提供的图）随 `build.icons.files` 打进包；打包前用户图不经任何修改。

### 验证与交付

- `app-icon-test` 7/7；main/preload/settings 三处语法检查通过；隔离 `--smoke` → `SMOKE_OK`。
- 可见预览实例：`%TEMP%\dsh-preview\app-icon-feature\`（隔离 home/userData/LOCALAPPDATA），
  PID **49888**，保持运行由用户试用：设置 → 外观 → 点「看板娘」即可看到窗口/任务栏图标变化，
  桌面快捷方式（若有指向本实例的）也会被改写。
- 注意：同版本自动更新不会重装，此功能将在下个版本随安装包发布。

## 移除外壳审阅侧栏 UI（改用 dsh-better-sidebar）+ 修好 better-sidebar 安装

### 背景

用户反馈外壳自带的「审阅」侧栏效果不如 dsh-better-sidebar（其内核插件的右侧栏界面），要求去掉外壳版。
查证 better-sidebar 在本机不可用的根因：profile 里的条目是指向工作区开发目录的链接（目标已消失=悬空），
内核"任一 bundle 失败即整体退出"→ 外壳隔离机制把它从 bundles 摘除保启动；种子一次性且"已存在即跳过"，
真包从未落地。修复时顺带发现 dsh-pet、@dsh-local/palis-theme-panel、cosmokit、schemastery 在 profile
node_modules 里也缺失（stage 按实际 import 闭包裁剪后，种子只跑过一次没能补全）——已全部按
安装包内置 stage 顶层逐个补齐，并把 dsh-better-sidebar 加回 bundles（只增补，不动其他条目）。

### 移除范围（界面层，谨慎保留底层）

- **preload.js**：整套 `dsh-review-*` 注入与渲染（330–1581 行，~1250 行）+ 引导调用删除；
  `PALIS_CHROME`（含断连浮层的 palis 方角样式）改由浮层自己的 style 注入——原来它搭审阅块的车。
  preload 1591 → 335 行。
- **保留内核侧 review-bridge 插件与 NDJSON 事件流**：窗口标题/托盘的「运行中」提示（agentBusy）
  由流里的 turn start/end 驱动，与审阅 UI 无关，摘了会退化。回退端点保留（loopback 闸 + 体积上限已加固）。
- **runUiSmoke**：侧栏存在性/展开/拖拽/git 视图/查看器断言全部移除，替换为
  「审阅界面已不再注入」的正向断言（与"特性已删除"同口径，不是删检查换通过——主题联动断言原样保留）。
- **删除四个只服务审阅 UI 的一次性脚本**与对应 npm 项：review-ui-check / sidebar-test /
  sidebar-layout-test / sidebar-skin-check。
- 保留：lib/git-review.js 及其测试（休眠的可测库）、panelWidth 设置字段与 IPC（无消费者，无害）。

### 验证

- better-sidebar：包已落 profile、bundles 已登记。**需重启内核生效**（托盘/菜单 → 重启内核，或重启应用）。
