## ② 启动画面二次重做：极简克制 · 单光环（取代 08-16 的「深海极光」版）

- **起因**：用户反馈「启动动画不好看」，并逐条确认了痛点：进度条来回横冲（假进度）、鲸鱼下的白色塑料光泽底板、背景太花（粒子星尘 + 网格 + 极光 + 光束）、围着 logo 转的两个圆环、进度提示重复三遍（胶囊 + 进度条 + 内核/服务/就绪三点）、进工作区时硬切；风格方向选定**极简克制 · 单一主视觉**，并授权按最佳审美重做。
- **做了什么**：
  1. **只留一个焦点**：删掉 Canvas 粒子系统（含整套 rAF/visibility 复活逻辑）、细网格、底部引擎光束、多层极光、独立暗角层 → 只剩「舞台底色渐变（自带暗角）+ 徽标背后一团 10s 极缓呼吸柔光」。
  2. **进度光环代替假进度条**：SVG 细环（track + 渐变弧 + 弧尖光点），弧长由**真实相位里程碑**驱动：`boot 4%→15% / kernel 17%→58% / wait 60%→93% / ready 100%`，里程碑之间做渐近爬升（每 200ms 逼近上限 8.5%，永远撞不到线）。唯一写入口 `advance()` 只接受更大的值 —— **单调递增、迟到的旧相位也不会把光环拉回去**；错误态就地**冻结**，不假装跑完。
  3. **扔掉塑料底板**：改用 `build/icon-whale-white.png`（白鲸透明底）直接落在深色场上，只留一层柔光 drop-shadow + ±2.5px 极轻浮动；原来的白色圆角光面底衬（内高光/内阴影）连同 `icon-whale-official.png`（黑鲸，必须垫白底）一起下线。
  4. **去掉三重冗余**：状态胶囊（双层扩散波纹）、流光进度条、三相步骤点全部删除，只留**一行状态文案**（切换时交叉淡入）+ 光环本身表达进度；日志尾巴改为**只在错误态出现**（原来正常启动也可能露出内部日志行）。
  5. **消除硬切**：新增淡出交接握手 —— 主进程 `shell:splash-exit` → 渲染侧整幕淡出（卡片 scale 1.035 + 淡出、柔光外扩，340ms）→ 回 `shell:splash-exit-done` → 主进程才 `loadURL`（520ms 兜底超时）。窗口背景色与启动画面同色，衔接处是无缝黑场。
  6. **交接节奏**：`MIN_SPLASH_MS=1250`（内核秒起也不把开场动画剪断）、`READY_HOLD_MS=420`（让光环可见地合环再走）；错误态「重新启动」成功后同样走合环 → 淡出 → 交接。
  7. **字标入场**：改为一次性淡入上浮 + 字距从 .1em 收紧到 -.008em（替代逐字上浮），克制且有质感。
- **改动文件**：
  - `renderer/splash.html`（DOM 从 8 层装饰 + 步骤条精简到「柔光 + 光环 + 白鲸 + 字标 + 一行状态 + 错误面板」）
  - `renderer/splash.css`（749 → 约 400 行，全部重写）
  - `renderer/splash.js`（重写：进度引擎 + 状态渲染 + 淡出，删掉粒子与逐字动画）
  - `preload.js`（新增 `onSplashExit` / `splashExitDone` 桥）
  - `main.js`（`MIN_SPLASH_MS`/`READY_HOLD_MS`/`SPLASH_EXIT_MS`、`state.splashAt`、`onSplash()`/`playSplashExit()`/`handoffFromSplash()`、restart 分支同步；另：**冒烟/UI 冒烟跳过 `applyAutoLaunch()`**，见下方坑）
  - `splash-check.js`（适配新 DOM，并新增「进度单调不回退」「错误态冻结」「淡出握手」「白鲸够亮/弧真的画出来」等断言；加看门狗与 uncaught 兜底，脚本再不会无声挂住）

  - **冒烟必须带独立 `--user-data-dir`**：userData 路径按 productName 取，会与**正在运行的打包版**撞单实例锁（触发 `second-instance` 把用户窗口拉到前台）；且测试实例的默认设置会经 `setLoginItemSettings` 按 AppUserModelId **抹掉用户真实的开机自启注册表项** → 已在 `main.js` 里让 SMOKE/UI_SMOKE 跳过 `applyAutoLaunch()`。

## ③ 外壳皮肤系统 + 第二套皮肤「海景 · Seascape」（致敬杉本博司《海景》）

- **起因**：用户提出「参考杉本博司的《海景》，设计一套启动动画和主题皮肤到设置里」。
- **设计推导（先定规矩再写代码）**：《海景》系列（1980– ）的三条硬规矩 → 直接变成实现约束与断言：
  1. **地平线永远在画面正中**，天与海各占一半 → `.sky`/`.sea` 各 50%，`.horizon` 落在 50%（回归里按 ±1px 卡）
  2. **单色银盐**，一丝彩色都不许有 → 全部灰阶取色，颗粒用 `feColorMatrix` 压成真灰（回归里按色偏 ≤14 卡）
  3. **无事件、无时间**（长曝光的静止）→ 除地平线外只有两处极缓呼吸：水平线聚光 16s、长曝光的浪 48s
  - **进度的表达**：既然地平线是这个系列唯一的"事件"，就让它当进度条 —— **从正中向两侧铺开**，铺满 = 就绪，失败就地停住。与深海皮肤共用同一个"永不回退"的进度数值（`paintProgress` 一处同时写光环 dashoffset 与地平线 scaleX）。
  - **构图**：版心放在下半幅（海里）—— 银灰鲸鱼 + 衬线宽字距字标 + 展签式 caption；上半幅（天）永远空着，这是《海景》的呼吸。
  - **失败态**：整幅印相退到后面（opacity .5）、地平线暗下去，错误面板做成"贴在照片上的一枚封条"（平、薄、只有一道暗红竖线）；构图本就被打断，所以失败时版心上探到 30% 并隐藏副标，保证最小窗口也放得下。
  - **退场**：版心先走，**地平线最后消失**（多留 .12s）—— 照片式淡出。
- **做了什么（工程）**：
  - 两套皮肤共用**一套 DOM**：`body[data-theme]` 切换，深海用 `.glow + .ring`，海景用 `.print`（天/海/浪/聚光/地平线/颗粒）；进度、状态、错误、淡出逻辑完全共用
  - **设置入口**：托盘 →「皮肤」子菜单（两项单选 + 预览启动画面/预览启动失败画面 + 两行边界说明）；`settings.theme` 持久化；切换即时生效（`shell:theme` 广播 + `win.setBackgroundColor`），已打开的预览窗口同步换皮肤
  - **预览窗口**：`splash.html?preview=1&theme=<id>` 自驱动一轮（拉起→等待→就绪→淡出→reload 重播），**绝不发 `splash-ready`/`restart-kernel`/`quit`**，不会把内核再拉一遍；`shell:splash-ready` 另加 `state.child || state.ready` 幂等闸门
  - **边界表态**：皮肤只作用于外壳自己拥有的界面。注入的审阅侧边栏一直在用**内核的设计令牌**（`--dsw-alias-*`）—— 刻意不染色，内核换主题时它自动跟随，这属于「内核零修改」
- **改动文件**：`renderer/splash.html`（加印相图层 + `.plate` 版心）、`renderer/splash.css`（+海景整套皮肤；`.mark`/`.print` 补 `pointer-events:none`）、`renderer/splash.js`（皮肤切换 + 地平线进度 + 预览模式）、`preload.js`（`onTheme` 桥）、`main.js`（`settings.theme`/`THEMES`/`themeId`/`applyTheme`/`openSplashPreview`/托盘子菜单/窗口底色/splash-ready 闸门）、`splash-check.js`（两皮肤 × 全项）、`splash-shot.js`（按皮肤出图）、`splash-preview.js`（`--theme=`）、`README.md`
- **结果**：
  - `npm run splash-check`：**163 项断言全过，exit 0**。关键数值：`horizon sits on the exact midline [horizon=449.08 mid=449.00]`、`sky and sea are equal halves`、`horizon 0.269 → 0.682 → 0.755（迟到旧相位不回退）→ 1.0000`、`px:seascape 单色 skyChroma=11 seaChroma=9`、`天比海亮 sky=38.9 sea=27.9`、`地平线是最亮的一条带 line=244 vs above=72/below=66`、`失败时 horizon 冻结 scaleX=0.293 且印相 opacity<0.9`
  - **冒烟（独立 userData）：`SMOKE_HANDOFF acked=true` + `SMOKE_OK url=http://127.0.0.1:9787`，exit 0**
  - 预览时间线实测：`kernel 0.267 → wait 0.706 → ready 1.0 → 淡出 → reload 重播`，全程未发出 splash-ready/restart/quit（探针脚本用完即删）
  - 六张预览图：`build/splash-preview-{deep,seascape}[-ready|-error].png`（gitignored），并用 ASCII 灰度图核过构图（空天 / 正中地平线 / 海里的鲸鱼与字标）
- **坑 / 备注**：
  - **窗口数归零会触发应用退出**：脚本里 `win.destroy()` 后再新建窗口，`load` 全部 `ERR_FAILED(-2)` —— Electron 默认的 `window-all-closed` 已经在退出应用。测试脚本一律**保持至少一个窗口存活**，收尾交给 `app.exit()`。（这条曾被误判成"file:// 带查询串不能加载"，白查一轮。）
  - **`loadFile(path, { query })` 在含空格的路径上会拼出非法 URL**（`file:///E:\Deepseek harness\...?theme=deep` → `ERR_FAILED`）→ 一律 `pathToFileURL()` + `searchParams`。托盘预览窗口走的正是这条路，属于**打包版也会翻车**的隐患，已修。
  - **`feTurbulence` 默认是彩色噪点**：直接当胶片颗粒会让"单色"断言炸（seaChroma=25）→ 加 `feColorMatrix` 压成灰度并固定 alpha=1。
  - **Windows 次像素抗锯齿会让文字边缘带 RGB 色边**（色偏 20~30），那是字体渲染不是调色板 → 单色断言的采样区刻意避开文字（只量天的整条带 + 海的左侧空白带）。
  - 皮肤要作用到**已安装的打包版**同样需要重新 `npm run dist` 并安装；仓库里可用 `npm run splash-preview -- --theme=seascape` 当场看。
