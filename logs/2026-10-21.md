## A. 做了什么

### 1. 注册表（`plugin/workbench/src/client/registry.js`）

- `normalizeMode` 收三个可选面：
  - `runtime`：必须有 `probe()`；`start` / `subscribe` 可选；
  - `jobs`：必须有 `list()`；`cancel` / `subscribe` 可选；
  - `artifacts`：必须有 `list()`；`open` 可选。
  - 半套（如 `runtime:{}` 没有 probe）**不登记**，`publicView` 如实标 `hasRuntime/hasJobs/hasArtifacts=false`。
- 新增读口：
  - `healthOf(id)`：**3 秒有界、绝不抛**；结果 2 秒缓存；超时按 `down` + `detail` 返回；probe 抛错按 `error`；
  - `startRuntime(id)`：只调用模式自己的 `start()`，返回结果如实；没有 start → `no-start`；
  - `jobsOf(id)` / `cancelJob(id, jobId)`；不能取消 → `no-cancel`（UI 据此不显示取消钮）；
  - `artifactsOf(id)` / `openArtifact(id, ref)`；只读句柄，不搬文件。
- `runtime.subscribe` / `jobs.subscribe` 已接线：回调清健康缓存并 `notify()`；注销时解绑。
- `notify()` 维护 `revision`，供 UI 在「状态变了」时重新探一次（仍不轮询）。

### 2. 接缝与瓷砖（`Chrome.js`、`copy.js`、`styles.js`）

- 新增 `ModeStatus` 组件：
  - 有 running/queued 任务 → 「渲染中 42%」（`progress` 缺失时写「渲染中…」）；
  - 后端 `down/starting/error` → 「后端未启动 / 启动中… / 后端异常」，`title` 带 `detail`；
  - `ready` 或无 runtime 面 → 不显示（正常态不占地方）。
- 接缝扇形、宽窗瓷砖头、模式大按钮卡三处都渲染这个徽标。
- 文案统一进 `copy.js`；颜色之外都带文字。

## B. 踩到的坑（如实记）

1. **`process.env.NODE_ENV = 'production'` 在 Electron 43 renderer 里抛 `Illegal invocation`**。
   `verify-workbench-writing-integration.cjs` 的假页原来用这行压 React 开发版警告；这轮跑回归时它先把探针打挂。
   修法：去掉赋值，在探针的 `console-message` 收集器里**只过滤** React 的 key 警告那一条（已知开发版告警），
   其余 error 照旧进 `errors`。
2. **L1.5 的 `setter.call(ta, …)` 在编辑器还没载入时炸成 `Illegal invocation`**（`ta` 为 undefined，
   原生 value setter 被错误调用）。修法：先 `waitFor` 编辑器里出现「第一章原文」，再取 textarea；
   取不到就抛明确的 `L1.5: textarea not found`。这不是产品 bug，是探针竞态。
3. **`healthOf` 缓存命中时返回的是普通对象，不是 Promise**：`ModeStatus` 一开始直接 `.then()` 会炸；
   改成 `Promise.resolve(registry.healthOf(...)).then(...)`。UI 探针第一次就抓到了（如果只写单测会漏）。
4. **`publicView` 加字段会打破“精确 key 集合”断言**：`test/registry.mjs` 那条 `Object.keys(view).sort()`
   同步补了 `hasRuntime/hasJobs/hasArtifacts`；这是有意的契约变化，不是把测试改绿。

### B.1 做了什么

- 新增内置插件 `plugin/previz`（`@dsh-local/previz`）：
  - **host** `index.js`：`/api/previz?route=state|probe|demo|cancel|open-blender|artifact`；
    `probeRuntime` 3s 有界/2s 缓存；`startDemo` spawn vendored 引擎的 `run-demo.mjs`；`cancelJob` 只杀自己 spawn 的进程树；
    `artifacts.list` 只读句柄；`artifact` 只允许 `OUT` 目录内、支持 Range。
  - **client** `src/client/*`：`previz` 模式注册（runtime/jobs/artifacts/splice/tile/context）、
    面板（运行/取消/打开 Blender/进度/日志/animatic/plan/接触表）、独立入口 + 全屏 overlay；
    有工作台时让出独立入口；工作台 `active==='previz'` 时渲染自己的全屏 overlay，关闭走 `exitPreviz()`。
  - **engine/**：vendored `blender-previz` P0 引擎（lib/blender/scripts/fixtures），避免插件运行时去工作区外找源码。
- 接入：
  - `BUILTIN_PLUGINS` 加 `previz`；
  - `prestart`/`predev` 加 `build:previz`；
  - `build.ps1` 打包前构建 previz client；
  - `package.json` extraResources 加 `plugin/previz`（含 `engine/**/*`）；
  - `scripts/build-previz-client.mjs` + `verify-previz-build.mjs` + `verify-previz-ui.cjs`；
  - `plugin/previz/test/{host,mode,sync,integration}.mjs`。

### B.3 踩坑

1. **真实壳 UI smoke 的 palis 红**：隔离 HOME 只有默认主题、没有 palis 插件/样式；不是 previz 加载失败。
   证据是同一份 console 里 `[workbench] client ready` 和 `[previz] client ready` 都在。
2. **Electron `ERR_UNSAFE_PORT`**：`verify-previz-ui.cjs` 随机端口撞上 2049，Chromium 直接拒绝加载；
   改成在 47820–47919 里找空闲端口。
3. **`ELECTRON_RUN_AS_NODE`**：跑 electron 探针前必须清（老坑 #1），清完 `verify:previz-ui` 才绿。
4. **`healthOf` 缓存命中返回普通对象不是 Promise**：UI 探针先抓到（老坑 #42），`ModeStatus` 用 `Promise.resolve(...)` 兜住。
5. **工作台“进入模式”不能空**：只给 `splice.view` 时，`active==='previz'` 会让模式自己缺少全屏面；
   已加 active 订阅 + 自己的 overlay（关闭走工作台 `setActive(null,'exit')`）。
