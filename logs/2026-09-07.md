# 2026-09-07

## 〔100〕 mac 构建管线修复——v0.1.19 起 dmg 从未产出（用户「看看mac版本是否同步推送了」）

#### 结论先行：mac 从未同步成功

v0.1.30 release 只有 Windows 三件套（setup.exe / latest.yml / blockmap）。
查 Actions：`build-macos` 从 v0.1.19 起共 12 次运行**全部 failure**（11-16 分钟
后倒在 "Build dmg" 一步）；连更早的 v0.1.18 release 里也没有 dmg——
"tag 推送后 GitHub Actions 自动补 mac dmg"（release.ps1 注释）从未兑现过。

#### 三重根因（按失败日志反推）

1. **过时的内嵌拷贝 + 目标目录缺失（直接死因）**：build-macos.sh step 4 把
   `runtime/node_modules` 用 `cp -R` 拷进 `.app/Contents/Resources/runtime/`——
   这是 v0.1.17 之前的旧架构（当前架构 = 归档 + 首启动解压）。且 `cp` 的目标父
   目录 `Resources/runtime` 在 .app 里根本不存在 → 逐文件 `No such file or
   directory` → exit 1。这条拷贝本身就该删除。
2. **从未打包 runtime.tar.gz + runtime-marker.json**：构建日志里
   `file source doesn't exist from=dist/runtime.tar.gz`——extraResources 引用的
   归档在 mac 侧从未生成（Windows 由 build.ps1 打，mac 的 build-macos.sh 没有
   对应步骤）。即使 cp 修好，.app 里也没有内核，首次启动 `ensureExternalRuntime`
   直接跳过归档、`resolveDynBin` 兜底也找不到运行时 → 无内核可用。
3. **prepare-runtime-macos.sh 不写 runtime.json**：Windows 侧
   prepare-runtime.ps1 写 `{dsh,node,builtAt}`，mac 侧漏了——`runtime-marker.json`
   无源，`ensureExternalRuntime` 无法比对版本。

**附加坑**：step 3 写成 `npx electron-builder --mac dmg --dir`——dmg 目标+`--dir`
混用，electron-builder 直接出了个**不含运行时**的残缺 `dsh-desktop-0.1.30-mac.dmg`
+ blockmap（日志 08:13:03 "building target=DMG"），很容易误判"其实构建过"。

#### 修复（提交 dd60d8b / a8779c5）

- **prepare-runtime-macos.sh**：runtime 就绪后写 `runtime/runtime.json`
  （`{dsh,node,builtAt}`，字段与 prepare-runtime.ps1 同构；dsh 版本经 argv 传入，
  注意该变量未 export，不能走 process.env）。
- **build-macos.sh**（对齐 build.ps1 两步法）：
  · runtime 就绪后立即 `tar -czf dist/runtime.tar.gz -C . runtime` + 复制方法
    `runtime-marker.json`（归档内容带 `runtime/` 前缀，与 Windows 同）；
  · step 3 改 `--dir`（不再传 dmg 目标，禁止中途产出残缺安装包）；
  · 删除过时的内嵌 node_modules 拷贝块；
  · step 5b 生成 `latest-mac.yml`——`--publish never` 不产清单，mac 检查更新会
    404（与 2026-08-25 Windows latest.yml 同坑不同面）。
- **gen-update-manifest.js**：新增第 4 参数输出文件名（缺省 latest.yml），
  mac 传 latest-mac.yml；本地实测（dummy dmg）输出格式正确。

#### v0.1.30 新代码 mac 兼容性核查（无问题）

hardenWindow(fileURLToPath/path.relative 均跨平台)、mdInline（纯 DOM）、
git-review(path.isAbsolute)、preload（contextBridge）——无 mac 特有 API；
打包态 `app.getAppPath()` = `.../Contents/Resources/app.asar`，isAppFileUrl 的
path.relative 判据对它成立。

- 资产：`dsh-desktop-0.1.30-mac.dmg`（185.69 MB / 194720239 B）+ `latest-mac.yml`

  （sha512/size 与 dmg 一致）、BUILD_DONE。mac 版本自此补齐——Windows 三件套
